# hotshotz-www
Strona hotshotz.pl – wersja robocza (kierunek „Newson”). Statyczny HTML/CSS/JS, bez WordPressa.

- `index.html` – strona główna
- `css/style.css`, `js/main.js`
- `img/` – kadry (WebP), logotypy (SVG)

Do zrobienia przed startem: plik showreelu w hero, podpięcie formularza, linki do realizacji, Parabolica (dodać domenę w Adobe Fonts), usunięcie `noindex` i `robots.txt`.
